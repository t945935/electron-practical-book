# 同一版本的分層驗收紀錄

複製此檔到 ZIP 外再填寫。Windows x64 ZIP 可攜部署，不含 MSI／Setup、安裝捷徑登錄、簽章或自動更新；userData 不跟程式目錄搬移。未測不是失敗，也不是通過。

## 身分

- 應用版本／來源版本：待填
- ZIP 名稱／SHA-256：待填
- Windows 版本／build／架構：待填
- 執行者／日期：待填
- 解壓位置／實際 userData：待填
- 乾淨 Windows 帳號或 VM／是否沒有 Node 等開發依賴：待填
- 通過狀態詞：實測通過、實測失敗、未測、環境受阻、不適用（需原因）。
- 各格附證據位置：命令、退出碼、預期及實際觀察；換 ZIP 雜湊另開紀錄。

## 與機器測試分開的使用者任務

另一位使用者依說明「新增待辦 → 保存筆記 → 搜尋 → 退出 → 重開」：未測。無測試者可自測但標明自測，不冒稱真人初學者成功。安裝器、簽章、自動更新範圍外，無需填本版缺失。

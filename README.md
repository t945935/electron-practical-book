# 《自己的工具，自己做》讀者服務

用 Electron 打造筆記本、計時器、檔案整理與個人桌面工具箱

作者：Happy eBook Authors

本儲存庫提供讀者支援、勘誤與配套程式使用說明，不提供書籍章節正文或完整教學內容。

## 配套程式

目前尚未發布配套程式或下載包。發布後會在此提供版本、下載方式及操作說明；請勿將目前的讀者服務頁視為已提供完整範例。

## 勘誤與提問

請先閱讀 [支援說明](SUPPORT.md)，再使用 [Issues](https://github.com/t945935/electron-practical-book/issues) 回報勘誤或操作問題。請勿貼上密碼、權杖、個人資料、完整書稿或未經授權的公司資料。
